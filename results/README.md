# Result files

- `survey-summary.json`: aggregate five-point responses by scenario, recomputed from S08.
- `legacy-random-forest-output.txt`: exact saved S05 console output.
- `model-metrics.csv`: three historical metric versions kept separate.
- `random-forest-feature-importance-11.csv`: S06 saved importance values extracted from workbook cells.
- `open-text-reason-categories.csv`: S01 cached chart categories and counts, plus English translations and recalculated shares.
- `replication-random-forest-metrics.json`: deterministic aggregate sensitivity-analysis metrics from S09.
- `replication-random-forest-permutation-importance.csv`: held-out permutation importance from the same audit.

No file in this directory contains respondent-level records or predictions. See [data and reproducibility](../docs/DATA_AND_REPRODUCIBILITY.md) for commands and limitations.
